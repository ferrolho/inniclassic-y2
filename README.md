# pr-media

Images and short GIFs for the pull requests of `ferrolho/inniclassic-y2` to `JonaszPotoniec/inniclassic-y2`.
This branch has no code and no common history with `main`. Do not merge it.

- One folder for each upstream PR number (`5/`, `27/`, ...).
- Screenshots: Innioasis Y2 (480×360), scaled ×2 with nearest-neighbour. "Before" = upstream `main`,
  "After" = upstream `main` + the PR branch, both on the same Y2 with the same data, theme Classic Light.
- GIFs: a screencap loop on the Y2 (~13 fps, true timing), converted with ffmpeg (palette, 10–25 fps, loop).
- The PR texts link the files as `https://raw.githubusercontent.com/ferrolho/inniclassic-y2/pr-media/<PR>/<file>`.
  Do not rename or delete a file that an open PR shows.
